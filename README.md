Task Management Web Application

This project is a Task Management Web Application developed using HTML, CSS, and JavaScript. The application allows users to create, update, and track their daily tasks efficiently.

The system includes a simple user authentication feature where users can sign up and log in to access the task manager. After logging in, users can add new tasks, edit existing tasks, mark tasks as completed, and delete tasks when they are no longer needed.

The application performs CRUD operations (Create, Read, Update, Delete) for managing tasks. All tasks are stored in the browser using Local Storage so that the data remains available even after refreshing the page.

The interface is designed to be simple, responsive, and user-friendly, allowing it to work on both desktop and mobile devices.

Technologies Used

- HTML for structuring the web pages
- CSS for designing and responsive layout
- JavaScript for application logic and task management
- Local Storage for storing user and task data

Features

- User Signup and Login
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Responsive design for multiple devices

This project helped in understanding the fundamentals of web development, including front-end design, JavaScript functionality, and basic data storage in web applications.
